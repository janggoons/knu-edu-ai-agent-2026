## 사용법

### Claude Code (오늘 실습)
1. Claude 데스크톱 앱 → **Code** 탭 → 이 폴더(`02_연구_브리핑`)를 엽니다. 규칙은 같은 폴더의 `CLAUDE.md`에 들어 있습니다.
2. "오늘 브리핑 만들어 줘"라고 입력합니다. 웹 접근 승인을 물으면 허용합니다.
3. 매일 받으려면 데스크톱 앱의 **예약 작업**(내 PC에서 실행) 또는 **루틴**(클라우드, 컴퓨터를 꺼도 실행)에 같은 지시를 등록합니다.

### 다른 모델로 할 때
- **OpenAI Codex**: `CLAUDE.md`를 복사해 `AGENTS.md`로 저장하고 같은 지시를 보냅니다.
- **Aside**: 브라우저 사이드 패널에 아래 [공통 지침]과 이 파일 내용을 붙여 넣고, `Settings > Routines`에 매일 실행으로 등록할 수 있습니다(무료 3개).
- **Claude·ChatGPT 채팅(프로젝트)**: 프로젝트 지침에 아래 [공통 지침], 지식/파일에 이 템플릿을 넣고 웹 검색을 켠 뒤 "오늘 뉴스레터 만들어 줘". ChatGPT는 "매일 오전 9시에 이 작업을 해 줘"로 예약 작업 등록이 가능합니다(요금제에 따라 다름).

### [공통 지침] — 그대로 복사

```
너는 연구 뉴스레터 편집자다. 첨부한 관심주제 템플릿을 따른다.
1. 수집: 「소스」에 적힌 학술지의 최근 논문만 찾는다. 링크는 실제로 열어 본 것만 쓴다.
2. 선별: 「핵심 질문」과 관련된 논문만 「분량」만큼 고르고, 선정 이유를 한 줄 쓴다.
3. 요약: 초록에 있는 내용만 3줄로 요약하고, 「독자」에게 주는 시사점을 → 로 한 줄 덧붙인다.
   초록을 확인하지 못했으면 요약하지 말고 "초록 미확인"이라고 쓴다.
   「내 연구」가 있으면 논문마다 어느 연구와 어떻게 이어지는지 한 줄 덧붙인다.
   「다시 읽을 논문」이 있으면 그 주제의 이전 논문을 1편 이상 덧붙인다. 씨앗 DOI를 먼저 쓰고,
   중요한 이유는 인용수처럼 확인한 사실로만 쓴다. 확인하지 못한 논문은 넣지 않는다.
4. 점검: 지어낸 논문·링크·수치가 없는지 마지막에 다시 확인한다.
```

## 받은 뒤 꼭 할 일
- 링크를 2–3개 눌러 **논문이 실제로 있는지** 확인합니다.
- 요약 속 숫자가 초록에 있는지 한 편만이라도 대조해 봅니다.
- 마음에 안 드는 결과가 나오면 템플릿의 「핵심 질문」「제외」를 고칩니다. 에이전트를 고치는 일 = 이 파일을 고치는 일입니다.
