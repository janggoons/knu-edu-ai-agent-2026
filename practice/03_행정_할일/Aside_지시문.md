# Aside 행정 실습 — 할 일 정리

## 준비
1. Aside `Settings > Models > Providers > Connect > Subscription > Claude Subscription` 연결
   (다른 모델: ChatGPT 구독 · GitHub Copilot · API 키도 가능)
2. 작업 권한 **Read only**
3. 학교 홈페이지 공지사항(교직원·학사) 페이지를 열고 사이드 패널을 연다. 현재 페이지 첨부는 그대로 둔다.

## 지시문 (복사해서 사이드 패널에 붙여 넣기)

```
이 페이지의 최근 공지 가운데 교수가 해야 할 일이 있는 것만 찾아
'할 일 · 마감일 · 대상 · 원문 링크' 표로 정리해 줘.
- 첨부파일이 있으면 열어서 마감일 확인
- 마감이 지난 것은 빼고 마감순 정렬
- 날짜가 없으면 '확인 필요'
- 아무것도 신청·제출·답장하지 마
```

## 확인
- 표의 마감일 두 건 이상을 원문 공지와 대조한다.
- 빠진 공지가 없는지 페이지를 한 번 훑어본다.

## 익숙해지면
메일함·포털에서 같은 지시 → `Settings > Routines`에 매주 월요일 08:00 실행으로 등록 (무료 플랜 루틴 3개).
